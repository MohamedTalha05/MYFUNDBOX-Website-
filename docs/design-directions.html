MYFUNDBOX — three visual directions

The same navbar, hero, dashboard preview and feature cards, shown in each direction. Recommended direction: A, Modern Minimal (reasons below). The logo mark is drawn as a placeholder here; the real site needs a dark-text logo, because the current wordmark is white.

A · Modern Minimal Recommended

Type: Geist (headings) + Inter (body). Precise, neutral, very legible at small dashboard sizes.

Feel: Paddle-level restraint. The colour comes from the logo's red, used sparingly; near-black primary buttons; one accent per screen.

Why it wins: it reuses the existing brand red, so there's no rebrand. It reads as trustworthy money software in the EU market. It also scales cleanly to a data-dense app UI and needs no gradients or decoration.

B · Premium Technology

Type: Sora (headings) + Inter (body). Geometric and techy.

Feel: Deep navy, electric blue and a violet accent. Developer- and enterprise-coded.

Trade-off: it clashes with the red-and-green logo, and blue-on-navy is visually close to Stripe and Maxio, so MYFUNDBOX would blend in. Dark pages are also heavier for long-form SEO content.

C · Contemporary SaaS

Type: Manrope (headings) + Inter (body). Friendly, rounded.
